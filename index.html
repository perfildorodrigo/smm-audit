SMM Audit

SMM Audit é uma ferramenta pessoal, de uso individual, que lê relatórios do Google Analytics 4 e do Google Search Console para análise de tráfego. Não é um serviço aberto ao público e não tem outros usuários.

Política de privacidade

Acesso solicitado. Somente leitura do Google Analytics (analytics.readonly) e do Search Console (webmasters.readonly), das propriedades a que a própria conta autorizada já tem acesso.

Uso dos dados. Os dados são usados apenas para gerar relatórios de tráfego para o próprio usuário. Não são vendidos, compartilhados com terceiros nem usados para publicidade.

Armazenamento. O token de acesso e os relatórios ficam no computador do usuário. A ferramenta não tem servidor próprio e não guarda dados em nenhum outro lugar.

Revogação. O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.

O uso das informações recebidas das APIs do Google segue a Política de dados do usuário dos serviços de API do Google, incluindo os requisitos de uso limitado.
